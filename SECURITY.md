# Security Policy

## Reporting a vulnerability

Please do **not** report security problems in public issues, discussions or pull requests.

Send the details to **bsurefy@gmail.com** with the subject line `SECURITY: <short summary>`. Include:

- the affected component and version (or commit),
- steps to reproduce, or a proof of concept,
- the impact you expect.

We confirm receipt within 3 working days, keep you informed while we investigate, and agree a disclosure date with you once a fix is available. We credit reporters who wish to be named.

## Supported versions

SurefyOS is in early development and has no stable release yet. Security fixes are made on the latest version only. This section will list supported release lines once versions are published.

## Scope

In scope: the code in this repository and the official container images built from it. Out of scope: deployments you operate yourself (for example, your server or network configuration) and third-party services you connect, such as AI providers.
